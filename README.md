# GrokStyle AI — инструкции по монетизации и настройке

Этот репозиторий содержит статический лендинг для продажи цифровых продуктов (промпты, мини-курс, консультации).

Что уже сделано
- Добавлены кнопки для быстрых оплат (placeholder-ссылки). Замените их настоящими ссылками на вашу платежную страницу.
- Добавлена форма захвата e-mail через formsubmit.co, настроенная на y644501@gmail.com. Если вы хотите другой адрес — отредактируйте action в index.html.
- Добавлена страница thank-you.html для перенаправления после заполнения формы.

Что надо сделать вам (быстрые шаги)
1. Создать продукт и checkout ссылку (рекомендуется):
   - Gumroad: создайте аккаунт, загрузите файл и используйте ссылку на продукт.
   - Stripe Payment Links: создайте ссылку на Checkout и вставьте её вместо https://example.com/checkout.
   - PayPal.Me / BuyMeACoffee: создайте аккаунты и вставьте свои ссылки.

2. (Опционально) Подключить рассылку и автодоведение файла:
   - Formsubmit.co отправляет заявки на почту. Для автоматической выдачи файла после оплаты используйте Gumroad/Stripe — они сами рассылают файл покупателю.

3. Включить GitHub Pages:
   - Settings → Pages → Branch: main, / (root) → Save
   - Ждите 1–5 минут, затем сайт будет доступен по https://<your-username>.github.io/ashab/

4. Добавить аналитику и отслеживание конверсий:
   - GA4 или Google Tag Manager: добавьте скрипт в index.html и отслеживайте клики по кнопке "Купить".
